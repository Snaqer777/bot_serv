# ПОЛИТИКА КОНФИДЕНЦИАЛЬНОСТИ

**Сервис:** VPN-доступ через Telegram-бота «Darktier VPN» · **Редакция от:** 22.09.2026 (переменная `TERMS_UPDATED`)

> Политика конфиденциальности — полная версия документа для репозитория.
> Тот же текст показывается в боте командой `/privacy` (планируется вместе с обновлением
> пользовательского соглашения — см. раздел «Как это подключено в боте» в конце файла).

Кратко: документ описывает правила обработки данных сервиса. Собираются идентификаторы аккаунта,
техническая информация и история взаимодействий — паспортные данные не требуются. Информация
используется для работы сервиса, связи с Пользователем и аналитики. Передача данных третьим лицам
возможна только по закону, для оплаты или с согласия Пользователя. Администрация хранит данные
необходимый срок и применяет разумные меры защиты, но не гарантирует абсолютную безопасность.
Пользователь несёт ответственность за риски передачи данных через интернет. Администрация может
изменять Политику без уведомления: продолжение использования Сервиса означает согласие с изменениями.

## 1. Общие положения

1.1. Настоящая Политика конфиденциальности (далее — «Политика») регулирует порядок обработки
и защиты информации, которую Пользователь передаёт при использовании сервиса «Darktier VPN» —
Telegram-бота и связанного с ним VPN-доступа (далее — «Сервис»).

1.2. Используя Сервис, Пользователь подтверждает своё согласие с условиями Политики. Если
Пользователь не согласен с условиями — он обязан прекратить использование Сервиса.

## 2. Сбор информации

2.1. Сервис может собирать следующие типы данных:

- идентификаторы аккаунта (Telegram ID, имя пользователя, отображаемое имя);
- техническую информацию (IP-адрес и объём трафика подключений, данные об устройстве
  и операционной системе в объёме, который передаёт клиентское приложение и Telegram);
- историю взаимодействий с Сервисом (заказы и платежи, факт принятия соглашения, обращения
  в поддержку, реферальные связи).

2.2. Сервис не требует от Пользователя предоставления паспортных данных, документов,
фотографий или другой личной информации, кроме минимально необходимой для работы.

## 3. Использование информации

3.1. Сервис может использовать полученную информацию исключительно для:

- обеспечения работы функционала (выдача и продление доступа, учёт тарифов, срока
  и лимитов трафика, отображение статистики в профиле);
- связи с Пользователем (в том числе для уведомлений, напоминаний об окончании подписки
  и поддержки);
- анализа и улучшения работы Сервиса (сводная статистика по тарифам и обращениям).

## 4. Передача информации третьим лицам

4.1. Администрация не передаёт полученные данные третьим лицам, за исключением случаев:

- если это требуется по закону;
- если это необходимо для исполнения обязательств перед Пользователем (например, при работе
  с платёжными системами: платёжный провайдер получает сумму и номер заказа для проведения
  платежа и возврата);
- если Пользователь сам дал на это согласие.

4.2. Для работы Сервиса данные обрабатываются техническими партнёрами (хостинг бота, сервер
VPN-панели, платформа Telegram) в объёме, необходимом для оказания услуги. Данные не продаются
и не передаются для рекламы.

## 5. Хранение и защита данных

5.1. Данные хранятся в течение срока, необходимого для достижения целей обработки: пока
Пользователь пользуется Сервисом и столько, сколько нужно для расчётов, поддержки и исполнения
требований закона. Историю платежей мы храним срок, необходимый для бухгалтерии и разбора спорных
ситуаций, в том числе после окончания подписки.

5.2. Администрация принимает разумные меры для защиты данных (ограничение доступа к панели
и хранилищам, служебные данные не публикуются), но не гарантирует абсолютную безопасность
информации при передаче через интернет.

5.3. Пользователь может запросить сведения о своих данных или их удаление, написав в поддержку:
[@Darktier_support](https://t.me/Darktier_support). Запросы обрабатываются по возможности быстро,
с учётом требований закона к хранению платёжной информации. Вместе с удалением данных доступ
к VPN отключается по запросу Пользователя.

## 6. Отказ от ответственности

6.1. Пользователь понимает и соглашается, что передача информации через интернет всегда
сопряжена с рисками.

6.2. Администрация не несёт ответственности за утрату, кражу или раскрытие данных, если это
произошло по вине третьих лиц или самого Пользователя.

## 7. Изменения в Политике

7.1. Администрация вправе изменять условия Политики без предварительного уведомления.

7.2. Продолжение использования Сервиса после внесения изменений означает согласие Пользователя
с новой редакцией Политики.

## Реквизиты Исполнителя

_Раздел для репозитория: **заполните** его своими реквизитами перед публикацией (в тексте
в боте эти строки не показываются)._

- Исполнитель: `TERMS_OPERATOR` — если переменная задана, строка автоматически попадает
  в подзаголовок соглашения в боте (например: `ИП Иванов И.И., г. Тверь, ИНН 000000000000`).
  Политика конфиденциальности использует те же реквизиты, что и Пользовательское соглашение.
- Поддержка: `SUPPORT_USERNAME` (Telegram) и `SUPPORT_EMAIL` (почта).
- Дата редакции: `TERMS_UPDATED`.

### Как это подключено в боте

- **Команда `/privacy` пока не заведена**: код бота менять на этом шаге не стали, сначала
  утверждается текст. Планируемый порядок: текст Политики добавляется в `bot.py` рядом
  с `terms_text()` (функция `privacy_text()`), команда `/privacy` и кнопка «🔒 Политика
  конфиденциальности» появляются на экране соглашения и в разделе поддержки.
- Пока Политика опубликована только в репозитории; Пользовательское соглашение ссылается
  на неё в разделе 8 («Конфиденциальность»).
- Какие данные бот действительно хранит: `data/terms.json` — Telegram ID и время принятия
  соглашения; `data/payments.json` — заказы (ID пользователя, тариф, суммы, идентификаторы
  платежей); `data/referrals.json` — реферальные связи. Файлы лежат на сервере бота
  (Railway); их стоит вынести на Volume, иначе они теряются при передеплое.
- В панели 3x-ui клиент привязан к Telegram ID (`tg-paid-<id>`) и хранит срок, лимиты
  и объём трафика — это и есть техническая информация из п. 2.1.
- При переходе на другого платёжного провайдера текст Политики менять не нужно: в п. 4.1
  провайдер назван обобщённо («платёжные системы»), чтобы смена кассы не требовала новой
  редакции документа.
