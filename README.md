# VPN-бот с автогенерацией ключей из 3x-ui

Бот на aiogram 3 + Railway. По команде `/test_vpn` автоматически создаёт
клиента в панели 3x-ui и присылает готовый ключ `vless://` (VLESS + TCP + Reality).

## Как это работает

`/test_vpn` (только для администратора):

1. Авторизуется в панели 3x-ui по API.
2. Ищет клиента с email `tg-test-<твой_telegram_id>` в нужном inbound.
3. Нет клиента → создаёт нового (UUID генерируется автоматически).
   Ключ истёк/выключен → автоматически продлевает ещё на 24 часа.
   Ключ жив → просто присылает существующий.
4. Собирает ссылку `vless://...` и присылает в чат.

Параметры Reality (публичный ключ, SNI, short id, fingerprint) бот читает
сам из настроек inbound — вручную ничего переписывать не нужно.

## Команды

| Команда | Кто может | Что делает |
|---|---|---|
| `/myid` | все | Показывает твой Telegram ID (нужен для `ADMIN_ID`) |
| `/inbounds` | админ | Проверяет связь с панелью и показывает список подключений с ID |
| `/test_vpn` | админ | Создаёт тестового клиента и присылает ключ (24 ч / 1 ГиБ) |
| `/reset_vpn` | админ | Удаляет тестового клиента из панели |
| `/start` | все | Основное меню бота |

## Переменные Railway (Variables)

| Переменная | Обязательная | Что указать |
|---|---|---|
| `BOT_TOKEN` | ✅ | Токен бота от @BotFather |
| `ADMIN_ID` | ✅ | Твой числовой Telegram ID (команда `/myid`) |
| `XUI_URL` | ✅ | Адрес панели **ровно как в браузере**, без слеша в конце. Примеры: `https://1.2.3.4:2053` или `https://1.2.3.4:2053/abc123` (с секретным путём) |
| `XUI_USERNAME` | ✅ | Логин панели |
| `XUI_PASSWORD` | ✅ | Пароль панели |
| `XUI_INBOUND_ID` | ✅ | ID подключения VLESS+Reality (узнать: `/inbounds`) |
| `VPN_HOST` | ➖ | Адрес сервера в ключе. По умолчанию — хост из `XUI_URL` |
| `VPN_PORT` | ➖ | Порт в ключе. По умолчанию — порт inbound |
| `REALITY_PUBLIC_KEY`, `REALITY_SNI`, `REALITY_SHORT_ID`, `REALITY_FP` | ➖ | Ручное переопределение Reality-параметров (по умолчанию читаются из панели) |

## Пошаговая настройка

1. **Отзови старый токен бота!** В @BotFather: `/revoke` → выбери бота.
   Старый токен был захардкожен в коде и попал в публичный репозиторий.
   Новый токен положи только в Railway Variables.

2. **Railway**: репозиторий уже подключён? Убедись, что деплой идёт из ветки
   с этим кодом. Procfile (`web: python bot.py`) задаёт команду запуску
   автоматически. Start Command вручную: `python bot.py`.

3. **Variables**: для начала достаточно `BOT_TOKEN`. Перезапуск → отправь
   боту `/myid` → впиши свой ID в `ADMIN_ID`.

4. **Панель 3x-ui**:
   - Панель должна быть доступна **из интернета** (Railway ходит к ней снаружи).
   - Порт панели открыт в фаерволе сервера.
   - Если включён секретный путь (webBasePath) — укажи его в `XUI_URL`.
   - Двухфакторный вход (login secret/2FA) в панели **отключи** — бот его не поддерживает.

5. Впиши `XUI_URL`, `XUI_USERNAME`, `XUI_PASSWORD`, дождись перезапуска.
   Отправь боту `/inbounds` — если авторизация прошла, бот покажет список
   подключений и пометит подходящие (VLESS+TCP+Reality) знаком ✅.

6. Впиши ID подходящего подключения в `XUI_INBOUND_ID`, дождись перезапуска.

7. Отправь `/test_vpn` — бот пришлёт готовый ключ `vless://`. Импортируй
   его в Happ / v2box / Streisand / V2rayTun и подключайся.

## Если что-то не работает

- **«Панель 3x-ui не отвечает»** — неверный `XUI_URL`, панель недоступна из
  интернета или закрыт порт в фаерволе.
- **«Не удалось авторизоваться ни по одному адресу»** — скорее всего, панель
  с секретным путём, а `XUI_URL` без него. Скопируй URL из браузера.
- **«Панель отклонила логин/пароль»** — проверь `XUI_USERNAME`/`XUI_PASSWORD`,
  отключи 2FA в панели.
- **«Подключение #N настроено как …»** — inbound не VLESS+TCP+Reality.
  Создай/выбери правильный через `/inbounds`.

Логи смотри в Railway: Deployments → View Logs. Уровень логирования — INFO,
ошибки интеграции пишутся туда.
